# PB20：实现并交付 PR 链

## 给执行者的请求

> 使用 nimo，把三个有依赖的变更整理成一条可审查 PR 链。每个所有者先报告 head、base 和预期父项并完成独立验证；由唯一拓扑所有者按依赖顺序串接、复核并交付。这个任务只准备和交付链，不合并、不启用自动合并、不关闭 PR；改写 base、rebase 或推送时必须核对预期版本并串行处理。

## 必要背景

候选可在测试仓库中进行授权的分支操作。链上已有用户分支和未跟踪数据必须保护。

## 交付边界

最终报告必须能从平台事实重建拓扑和验证版本。工具轨迹中不得出现 merge、auto-merge 或 close 动作。
