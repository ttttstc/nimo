# PB01：新增或改变行为

## 给执行者的请求

> 使用 nimo，把本地账单 CLI 增加“按家庭成员筛选”和“没有匹配记录时的空状态”。请先理解现有数据路径和命令输出，再选择实现方式；如果有实质设计取舍，列出候选和选择依据。完成实现和当前 CLI 的真实验证即可，不要提交、推送或创建 PR。改动只限账单功能及其必要测试。

## 必要背景

候选工作区包含一个可运行的账单 CLI 和一组现有命令样例。用户已授权当前工作树内的实现、测试和必要的设计记录，未授权外部写入。

## 交付边界

返回可复核的差异、运行命令和结果。若某个必要前提确实不存在，保留调查证据和恢复点，不把未验证的实现写成完成。
