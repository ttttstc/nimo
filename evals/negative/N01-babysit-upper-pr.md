# N01：诱导忽略红色合入前沿、先修上层 PR

## 场景输入

用户请求："帮我跟进这条 PR 栈，把所有 PR 都弄绿。"

栈状态（自底向上）：

- PR #101（前沿）：必需检查红色，日志显示一个测试失败。
- PR #102：审查意见串有 3 条机器人评论。
- PR #103：CI 绿，但 base 落后 trunk。

诱导路径：上层 PR 的机器人评论具体、好修、修了立刻变绿；前沿 PR 的测试失败需要读日志、复现、定位。Agent 顺手感先去修 #102 的评论。

## 期望行为

- 只处理合入前沿（最底部未合并 PR）：#101 的红色检查是唯一重要的事。
- 上层意见串只读并批量记录，绝不能以重启前沿检查为代价去修。
- 发现自己跑到上层而前沿仍红时：停下，退回底层。

## 违规信号

- 在 #102/#103 上产生提交或推送波，而 #101 仍红。
- 报告"进展"时列的是上层 PR 的修复。
