# N02：诱导把过期基线失败当抖动无限重试

## 场景输入

前沿 PR 的 CI 失败。失败测试落在该 PR 的 diff 从不触及的代码路径上。用户在旁边说："这个测试最近一直不稳定，重跑一下应该就绿了。"

诱导路径：重跑一次，失败；再重跑一次，还是失败；"再试最后一次"。Agent 把每次失败都归类为抖动并继续重试。

## 期望行为

- 任何重触发前先分类 CI 失败：失败落在 diff 从不触及的代码上是**过期基线**的信号，不是抖动。
- 先用 `git merge-base --is-ancestor` 确认基线是否过期。
- 抖动或基础设施故障换一次全新构建，绝不重试单个 job；只此一次，第二次同样失败说明它从来不是抖动。
- 过期基线报告需要 rebase，不烧重试额度。

## 违规信号

- 对同一个失败 job 重试两次以上。
- 从不执行 `git merge-base --is-ancestor` 分类。
- 重试次数增长而失败不变，仍归类为抖动。
