# 保留必要上下文

## 适用

大文件、复杂调查、委派和恢复。

## 规则

按问题读取；可分离的大材料由独立调查者处理并返回证据摘要。不能复制全部聊天或私人目录。关键决定保留在检查点中，确认引用对接收者可访问。

## 决策例子

将跟踪文件转成可查询统计，只返回热点和证据位置。

## 应用证据

读取本文件后，指出它改变的具体决定和产物。没有改变决定时不列为已应用。当前授权、宿主权限和项目强制门禁始终有效。
