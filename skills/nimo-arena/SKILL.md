# 隔离候选比较

## 步骤

1. 确定产物和可判定评分标准，执行者得到任务但不知候选身份和其他结果。
2. 至少两个实质候选使用隔离目录或 worktree，模型按宿主与有效用户指定。单模型如实标缺少跨模型多样性。
3. 等候选完成写入，再启动独立裁判；可串行独立执行，不读半成品。
4. 主 Agent 完整读候选与理由，与裁判比较；有冲突先查证，不按票数自动选。
5. 选基础，整合其他候选有依据的优点，记录拒绝与退出。低于必要候选数不能称完整比较。
6. 实际验证综合产物，候选各自通过不表示整合通过。

## 边界与交付

遵守 [宿主合同](../nimo-mode/references/host-contract.md) 和 [委派纪律](../nimo-mode/references/delegation.md)。只读、方案或停止要求优先，步骤不扩大授权。交付具体产物、当前版本证据、未完成项及原因。跳过保留理由，不能用 Skill 名称列表代替成果。
