# 让类型排除错误

## 适用

类型、签名和外部数据边界。

## 规则

外部数据在边界解析；用联合类型表达互斥状态，区分含义不同的基础值，穷尽处理变体。不用断言掩盖未知；从权威定义派生类型，只在防止真实无效状态时增加精度。

## 决策例子

完成与失败使用不同分支，不能完成但缺证据。

## 应用证据

读取本文件后，指出它改变的具体决定和产物。没有改变决定时不列为已应用。当前授权、宿主权限和项目强制门禁始终有效。
