# 独立质疑与审查

## 步骤

1. 明确目标、差异版本、周边约束和预期行为，不重新决定用户目标。
2. 独立审查者得到同一任务标准，可用时不同模型；只有同模型独立上下文时记录限制。
3. 每个发现要有位置、触发条件、影响与证据；意见一致不是证明。
4. 主 Agent 去重核实，分类处理、考虑、记录、驳回，说明取舍和反证。
5. 只交付审查结果，不自动改代码。自检不能称独立审查。

## 边界与交付

遵守 [宿主合同](../nimo-mode/references/host-contract.md) 和 [委派纪律](../nimo-mode/references/delegation.md)。只读、方案或停止要求优先，步骤不扩大授权。交付具体产物、当前版本证据、未完成项及原因。跳过保留理由，不能用 Skill 名称列表代替成果。
