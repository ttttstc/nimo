# 组织独立分片与竞赛

## 步骤

1. 明确全覆盖、first-pass、全排名或择优，列必要分片、产物、标准和停止条件。
2. 按实际容量分批或滚动启动；每个执行者有完整合同及独立可写位置，不固定模型或云环境。
3. 核对全部终止结果。覆盖必须所有必要分片有证据，竞赛按预先规则选。失败不能从统计删除。
4. 主 Agent 审阅整合，报告证据和缺口。无独立上下文不扮演虚假 Agent。

## 边界与交付

遵守 [宿主合同](../nimo-mode/references/host-contract.md) 和 [委派纪律](../nimo-mode/references/delegation.md)。只读、方案或停止要求优先，步骤不扩大授权。交付具体产物、当前版本证据、未完成项及原因。跳过保留理由，不能用 Skill 名称列表代替成果。
