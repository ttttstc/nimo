# 验证真实用户结果

## 步骤

1. 固定产物版本、验收场景与操作面，优先读项目 .nimo/verification/SKILL.md 和相关功能条目。
2. 选择实际工具：CLI 用终端，UI 用浏览器或设备，服务用对应接口；缺失不伪造。
3. 记录本次实例、端口、数据与所有权，实际操作并检查可见结果。
4. 先固定预期结果，再把实际输出逐项比对；只打印结果不算通过。保存版本、Shell、完整参数、操作、输出和时间。更换 Shell 时确认参数含义相同，参数转发失败不能误判成业务结果。编译和内部方法测试不替代原操作面。
5. 只清理本次实例，证据在清理范围外。缺条件记未验证，不放宽预期。
6. 独立验证由未参与实现的上下文执行，主 Agent 再读取差异与证据验收。

## 边界与交付

遵守 [宿主合同](../nimo-mode/references/host-contract.md) 和 [委派纪律](../nimo-mode/references/delegation.md)。只读、方案或停止要求优先，步骤不扩大授权。交付具体产物、当前版本证据、未完成项及原因。跳过保留理由，不能用 Skill 名称列表代替成果。
