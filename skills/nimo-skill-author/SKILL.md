# 编写可运行 Skill

## 步骤

1. 明确触发、不适用场景、输入、步骤、产物、验证、失败和停止，保持最小职责。
2. name 与目录一致，description 说明何时用；必要长材料用真实相对链接。
3. 不依赖私有元数据或假工具，不自动安装第三方 Skill，缺失明确受阻或等价方式。
4. 检查全部引用，使用自然任务检验行为。结构与权限变化须验证，纯主观措辞可说明不适用。
5. 用 nimo-technical-writing 和 nimo-unslop 精简，只交付必要文件。

## 边界与交付

遵守 [宿主合同](../nimo-mode/references/host-contract.md) 和 [委派纪律](../nimo-mode/references/delegation.md)。只读、方案或停止要求优先，步骤不扩大授权。交付具体产物、当前版本证据、未完成项及原因。跳过保留理由，不能用 Skill 名称列表代替成果。
