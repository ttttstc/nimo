# P1 Playbook 移植账本（playbooks-p1-b）

上游固定版本：pstack/skills/poteto-mode/playbooks @ 93b00b89ef425a9c1bac0d0b317dfc49c930ac99。本表记录 authoring-a-skill（PB11）、opening-a-pr（PB13）、session-pickup（PB21）、pause-safely（PB22）、worktree-cleanup（PB23）五个 Playbook 相对 upstream 的每个有意义适配；纯语言翻译不算差异，不记录。

适用于全部五个文件、不逐行重复的共性适配：

- 语言改为中文，全部会改变执行行为的语义（MUST/NEVER/ALWAYS、停止条件、失败分类与恢复规则、判断信号、anti-pattern、evidence/verdict/checkpoint 规则、"为什么这个步骤存在"、"什么信号说明执行错了"）等价保留，未压缩成口号。
- 命名映射：create-skill→nimo-skill-author、/deslop（cursor-team-kit）→nimo-deslop、/no-comments→nimo-no-comments、/technical-writing→nimo-technical-writing、/unslop→nimo-unslop、interrogate→nimo-interrogate、show-me-your-work 轨迹→nimo-show-me-your-work、"Opening a PR"→链接 opening-a-pr.md（整理并创建 PR）、"Autonomous run playbook"→链接 autonomous-run.md（持续完成一个目标）、"Session pickup playbook"→链接 session-pickup.md（接续已有工作）、babysit→链接 babysit.md（检查或跟进）；scope 示例 `pstack`/`poteto-mode`→`nimo-mode`/具体包名；Verification 示例 `control-cli`/`control-ui`→实际驱动的 CLI、UI 操作面或目标测试；"restart Cursor"→"重启宿主"。
- 平台差异按跨平台等价表达：`/tmp/<slug>-resume.md`→系统临时目录或任务目录下的 `<slug>-resume.md`；`df -h /`→磁盘占用快照（`df -h` 可用时用）。
- Cursor Task 工具派子 Agent 改为宿主独立子 Agent；委派步骤统一附降级规则（宿主合同/委派纪律：无子 Agent 时主 Agent 顺序执行并记录降级，不称独立）。
- 增加 nimo 授权边界：推送、PR、评论、合并等外部动作受用户当前授权约束（PB11、PB13）；暂停不自动授权提交（PB22）；worktree 删除仅对确认集在授权内执行（PB23）。
- nimo 结构约定：标识行、"执行前读取"、"必要条件与停止"（upstream 停止条件忠实移植 + 各文件既有 nimo 授权内容保留）、公共规则行、"所需 Skill"（按正文实际引用）、"交付"（既有 nimo 语义 + upstream Reply 内容合并）、"来源"行。
- "执行前读取"清单在原摘要版基础上按 upstream 正文引用补充原则链接：PB21 补 guard-the-context-window；PB23 补 build-the-lever、encode-lessons-in-structure、guard-the-context-window、never-block-on-the-human。
- 检视点名恢复的语义（PB11 每句正文必须改变决定／能删则删／结构来源优先／不复述其他 Skill 正文；PB13 worktree/commit/stack 纪律与 PR body 五节结构；PB21 inheritance-first 与 done vs pending；PB22 atomic boundary 与 cold-start resume note；PB23 audit→usage verification→irreversible-loss gate→prune→verify reclaim 方法）均为等价恢复，正文已完整落回，下表只列恢复项中最需要人工对照的条目。
