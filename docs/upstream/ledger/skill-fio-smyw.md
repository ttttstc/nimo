# Skill 移植账本：nimo-figure-it-out 与 nimo-show-me-your-work

- 上游来源：pstack（cursor/plugins 仓库，固定 SHA `93b00b89ef425a9c1bac0d0b317dfc49c930ac99`）的 `skills/figure-it-out/` 与 `skills/show-me-your-work/`（含 `references/decision-log-template.tsv` 与 `scripts/log.sh`）。
- 本账本只记录相对上游的有意义适配。纯中文化翻译与统一命名适配不逐条记录，包括：figure-it-out→nimo-figure-it-out、show-me-your-work→nimo-show-me-your-work、poteto-mode→nimo-mode、architect→nimo-architect、arena→nimo-arena、unslop→nimo-unslop、原则 Skill 名加 `nimo-principle-` 前缀、粗体引用改为正文内联相对链接、"worker/helper" 统一译为"执行者/被委派者"。
- 语义等价要求：上游中所有改变 Agent 决策/执行行为的强约束（MUST/NEVER 级语义）、停止条件、判定信号（VERIFIED / NOT VERIFIED / INCONCLUSIVE，且 INCONCLUSIVE 不是通过）、anti-pattern（空白截图骗过懒惰门禁、把整条轨迹攒到最后补写、复述列定义、修故事不修日志）、TSV 每一列的语义、"为什么这个步骤存在"、"什么信号说明执行错了"均已逐条保留等价语义，未压缩。
- 表头说明：artifact=受影响的产物；upstream rule=上游规则；nimo adaptation=nimo 侧适配；reason=适配原因（对应移植任务允许的适配类别）；semantic impact=对执行语义的影响；verification=验证方式。
