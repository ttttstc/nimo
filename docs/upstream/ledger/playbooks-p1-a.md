# P1 Playbook 移植账本（playbooks-p1-a）

上游固定版本：pstack/skills/poteto-mode/playbooks @ 93b00b89ef425a9c1bac0d0b317dfc49c930ac99。本表记录 investigation（PB03）、prototype（PB05）、runtime-forensics（PB08）、trace-forensics（PB09）、visual-parity（PB10）五个 Playbook 相对 upstream 的每个有意义适配；纯语言翻译不算差异，不记录。检视定为 P1：主路径基本正确，但摘要版丢失 upstream 的 operational detail，本批逐文件按 upstream 全文重新忠实移植，检视点名恢复的语义在各行"等价恢复"中体现。

适用于全部五个文件、不逐行重复的共性适配：

- 语言改为中文，全部会改变执行行为的语义（MUST/NEVER/ALWAYS、停止条件、失败分类与恢复规则、判断信号、anti-pattern、evidence/verdict 规则、"为什么这个步骤存在"）等价保留，未压缩成口号。
- 命名映射：how→nimo-how（Explain／Critique 模式名保留）、why→nimo-why、architect→nimo-architect、unslop→nimo-unslop、"Feature"→链接 feature.md（新增或改变行为）、"Bug fix"→bug-fix.md（缺陷修复）、"Perf issue"→perf-issue.md（一次性能问题修复）、"Opening a PR"→opening-a-pr.md（整理并创建 PR）、"Runtime forensics"→runtime-forensics.md（运行时取证）、各 principle skill→nimo-principle-<名字>。
- Cursor 私有 control skill（chrome devtools MCP 等 UI 控制接口）统一改为"匹配的操作面（按 nimo-verify 真实操作面规则）＋ 宿主提供的控制／调试能力"，并沿宿主合同降级：无真实操作条件时验证受阻，不用源码审阅充当。
- 增加 nimo 授权边界：runtime-forensics 的 live instrumentation／hotfix 属运行状态修改，须用户相应授权；推送、PR、评论、合并等外部动作受用户当前授权约束；PR 步骤一律"按授权运行"。
- nimo 结构约定：标识行、"执行前读取"（摘要版清单基础上按 upstream 正文点名引用补充原则链接）、"必要条件与停止"（upstream 停止语义＋各文件既有 nimo 授权内容）、公共规则行、"所需 Skill"（按移植后正文实际引用）、"交付"、"来源"行。
- 只读类流程的 "Throughput checkpoint stays one line" 保留为一行记法（`吞吐量检查点：n/a，只读调查／只读取证`），并保留"四项版本只用于代码形工作"的区分。
