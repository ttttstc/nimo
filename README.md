# nimo

**AI 原生工程栈。** 在现有 AI 编程工具中，通过一个入口获得工程指导或执行研发任务。

> 当前处于总体设计阶段，尚未提供可安装实现。下列能力和调用方式为目标设计，宿主支持将以实际验收结果为准。

## 一个入口

知道要做什么时，让 nimo 执行；不知道下一步时，让它根据项目现状给出指导。

```text
$nimo 这个需求接下来应该怎么推进？
$nimo 看看方案还缺什么，先不要实现。
$nimo 修复登录后一直加载的问题，复现并验证。
```

nimo 根据自然语言识别意图，优先遵守“先讨论”“不要修改”“开始实现”等明确要求。

## 核心能力

- **工程指导与任务执行**：按任务选择工程做法，给出下一步或完成明确工作。
- **按需加载工程原则**：围绕事实、最小修改、状态设计和验证形成具体判断。
- **可替换研发 Skill**：提供默认组合，支持项目覆盖，保持统一质量要求。
- **子 Agent 协作**：非简单实现默认委派，主 Agent 负责验收；启动规格采用宿主默认，有明确指定时优先使用指定值。
- **项目验证与功能地图**：记录功能入口、操作方式和成功条件，驱动真实产物验证。
- **检查点与恢复**：长任务保留必要记录，恢复前核对现场和证据版本。
- **Skill 评测维护**：用真实案例比较变更，检查回归后更新版本。

## 工具接入计划

Codex 为首个完整验收目标，Cursor、Claude Code 逐一接入。核心工程内容共用，工具、模型和子 Agent 使用宿主原生能力。缺少必要能力时明确报告限制。
